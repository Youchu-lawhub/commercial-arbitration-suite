# 模板：`.arbitration-config.md`（冷启动配置文件）

用法：复制到用户指定的案件工作目录，改名 `.arbitration-config.md`，依据已确认的用户信息与实际能力填写。
`- slot(name): value` 行是 `route.py --detect` 的解析目标，**格式不得改动**；未确认的槽位写 `UNBOUND`，
`--detect` 会以 `CONFIG_INCOMPLETE` 退出码 2 拦下后续起草（铁律 4）。无关可选槽位可 skipped；实际状态与理由一并记录。

```markdown
---
title: 案件配置
case: [[案件代号]]
mode: memo
---

# [[案件代号]] 配置

## 一、案件坐标

~ 机构：[[ICC / SIAC / HKIAC / LCIA / SCC / CIETAC / 其他]]
~ 适用规则版本：[[icc-arb-2021 等 source-id]]（由 fetch_official.py applicable --commencement 判定）
~ 仲裁启动事件与日期：[[已确认收件/送达事件及 YYYY-MM-DD；新拟条款写尚未启动]]
~ 仲裁地（seat）：[[城市, 法域]]
~ 仲裁语言：[[English / 中文 / 双语]]（依条款或约定）
~ 合同准据法：[[法域]]（实体结论须走 11-governing-law）
~ 我方地位：[[申请人 / 被申请人 / 反请求方 / 谈判方]]
~ 争议金额与币种：[[amount / currency]]
~ 工作目录：[[/abs/path/to/case]]
~ 涉外因素判定：[[IN_SCOPE]]（依据：[[主体涉外／标的涉外／法律事实涉外／仲裁地或准据法涉外／执行地涉外 之任一]]）

## 二、能力槽（逐行确认，不留空）

- slot(official_rules_fetch): [[bound (fetch_official.py + data/official) | degraded (manual download)]]
- slot(law_retrieval): [[bound (<通道名> @ <日期>) | degraded (official-urls only)]]
- slot(docx_render): [[bound (render_docx.py, no third-party deps) | degraded (markdown only)]]
- slot(local_corpus): [[bound (<已解析知识库路径>) | skipped]]
- slot(company_research): degraded (official registries; select by incorporation jurisdiction)
- slot(party_data): user-materials-only (固定值，套件不代为认定主体信息)

## 三、降级后果（对应槽位为 degraded 时生效）

~ official_rules_fetch 降级：文书中所有条号写 `[[适用规则条号待官方文本核对]]` 占位，不得引用具体条文。
~ law_retrieval 降级：只输出检索路径与官方来源清单，境外法结论一律标"需外部律师意见"。
~ docx_render 降级：只交 `.md`，并在交付说明中写清如何转 Word；《中文审阅说明》仍须同出（铁律 5）。

## 四、刷新与核验节奏

~ 规则与指引缓存刷新：[[YYYY-MM-DD]] + 90 天
~ 官方来源校验记录：[[data/_provenance/<source-id>.json 已生成]]
~ MCP 验收结论与日期：[[bound / degraded，验收日期]]

## 五、保密设置

~ 文件名脱敏规则：[[只写案件代号，不写对方全称与争议标的细节]]
~ 材料只写入工作目录：[[已确认]]（不写入技能包与 data/，不外发）

## 六、内置规则版本核验

~ 本案适用机构：[[机构 key]]
~ 套件内置版本：[[source-id]]（生效日期 [[YYYY-MM-DD]]）
~ 内置版本置信度：[[high / medium / low]]
~ 抓取状态：[[ok / blocked / manual]]
~ 核验操作：[[已自动取文 / 需用户导入 PDF / 已用户导入]]
~ 版本更新检查：[[当前为最新 / 官方已发布新版待确认 / 无法联网检查]]

> 版本清单见 `references/institution-rule-versions.md`。
> 若抓取状态为 `blocked` 或 `manual`，用户须从官网下载规则 PDF 后运行 `fetch_official.py import <source-id> <文件路径>` 导入。
> 若官方已发布新版规则，套件提示用户确认后重新取文并更新版本登记。
```

## 填写纪律

- 已在会话明确或已探测的项目直接登记，不重复提问；未知案件事实须用户确认后才落笔；推断值只能写成"待用户确认的默认项"并加 `[[…]]` 高亮占位（铁律 3、4）。
- 机构与规则版本不一致时（条款约定旧版本、启动日落在新版本），把两说都记下来并先向用户确认，不得静默取其一。
- 涉外因素五项全部为否或不明 → 本轮不产出任何文书，回到 `00-cold-start` 的拒绝话术。
- 填完后运行 `python3 <suite>/scripts/route.py --detect --workdir <案件目录>`，非 `CONFIGURED` 不进入下一子技能。

## 个性化检索偏好（可延后至具体法域）

记录用户指定的 research-profile.json 路径、已有数据库/连接、默认能力选择及法域/任务覆盖；不写账号密码。选择模板见 `references/research-personalization.md`。不设置供应商强制依赖。
