# 庭审与庭后

开庭不是新写一轮书状，而是把已固定的证据按仲裁庭能吸收的顺序重讲一遍。涉外范围以 `00-cold-start` 的 `route.py --scope` 结论为准；涉及准据法解释规则的实体内容一律转 `11-governing-law`（铁律 6）。

## 一、入口闸门

材料要求以 `suite.yaml` 的本子技能条目为唯一依据。已在会话中明确的事实直接登记，不重复索取。
对实际案件，先核对本案配置，再把已读取的材料逐项登记到案件根 `case.json`（`rulesuite-case/1`）；台账 `case` 与配置一致，Markdown 清单仅由台账生成供人阅读。

```bash
python3 <suite>/scripts/route.py --gate 09-hearing --profile <文书类型> --workdir <案件目录> --provided <案件目录>/case.json
```

本子技能任务类型：`hearing`、`post-hearing`。只选本轮需要的文书类型，不把其他类型的必填项合并进来。

未通过时，针对影响本轮结论的缺项提问；可先整理已知事实、检索路径与明确标为未完成的框架，不虚构事实，不交付未核验定稿。通用教学或规则导航问题不要求伪造案件配置。

## 二、动作

- 先读取当前 `案件档案/case-matrix.yaml`（schema 2）、争点与卷宗终版及 `references/case-construction.md`，沿 E → F → EV → A → 实际 R 组织开场、询问、结案与庭后答复，不从旧书状重建另一套事实。
- 记稿声明 `workflow: 09-hearing`、所选 `profile: hearing|post-hearing`（二选一）、`matrix: case`；`case` 仅写稳定代号。庭后只核本轮指令与记录，不倒逼补齐无关庭前材料。
- 实质段附近写内部追溯行，如 `#! 锚点：F-001 / E-CL01-01 / EV-001 / R-01 / A-01`；F/E/EV/R/A 仅列实际依赖编号，不用 `[[F]]` 或 `[[F-001]]`。另保留庭审记录页/行、卷宗页和对外附件号，`#!` 不进入 Word。
- 庭上承认、证言变化、被排除证据及新指令先回写底账版本和来源，刷新受影响论证；不得为统一口径抹去不利记录或未经许可引入新请求。
- 纯否认不强造本方 CL/R，非金钱事项不强加金额、币种或利息；已付款与回收抵减后再核主文，未确认汇率分币种列示。
- 庭前及提交前留存 AT/PM 对抗审查与预演失败、回应及残余风险；自审标 `self_review`。交 12 前用 `case_matrix.py anchors --in <矩阵路径> --draft <文书.md>` 和 `check --in <矩阵路径> --stage draft|submission` 选本轮阶段检查。

1. **倒排庭前里程碑**（以开庭日为 T 日，按 `references/procedural-timetable.md` 初排再与程序令对齐）：T−21 天定争点与证据清单终版；T−14 天核心卷宗（core bundle）与全套 bundle 完成并统一分页编号；T−10 天演示材料按程序令截止日电子提交；T−7 天预读函与时间线；T−5 天证人庭前指引与出庭顺序确认；T−2 天议程回执与用时表定稿。程序令写明的截止日早于上述推算值时，以程序令为准并记录冲突。
2. **卷宗与目录格式**：一次固定编号体系（C‑/R‑ 序列、卷宗页码、证据与证人陈述段落互引），目录按争点而非按时间分组，每份文件标注其在哪个证人陈述/哪段书状中被引用。预读函控制在一页内：只推荐"读一次就够"的核心段落，给准确段落号与页码，注明哪些旧材料已被替代，中立描述不作评价，**必须抄送对方**——单方联系仲裁庭本身就是程序瑕疵指控的来源。
3. **时间分配按小时而非天数**：可用水时 − 休息 − 程序讨论 − 开场陈述 − 仲裁庭提问 = 可分配询问时，双方各半并写明余数处理。每位证人主询问设上限、超时由仲裁庭直接切断；仲裁庭提问占用其自身时间；超过一两分钟的异议计入异议方时间；由秘书保存"平等用时"记录。把这几条写死进议程，可消除庭审日大半争执。
4. **议程与庭审程序令的固定要素**：席位与日期及每日起止 → 出席名单 → 各开场陈述最长分钟数 → 证人顺序表（姓名／提名方／出庭日／证言语言／主问·盘问·再盘问·仲裁庭提问预估时长）→ 每位证人须出庭否则其陈述不予考虑及二次传唤机制 → 盘问限于陈述主题与可信度、再盘问限于盘问新出现事项 → 演示材料截止日及"不得借此引入新论据或新证据" → 速录/录音方式、订正程序与副本费用归属 → 语言与传译及预留时间 → 证人出庭前不得在场 → 可采性争点的处理时点 → 仲裁庭限制或排除提问的权力 → 是否口头结案或改交书面意见及庭后简报与费用陈述日期 → 应急条款与仲裁庭修改权。
5. **远程/混合开庭单列一节**：连接方式与备用通道、屏幕共享与材料出示（提前提交、庭上不发放新演示材料）、证人镜头与证件核验、笔录逐字与延迟、录音录像禁止、各时区截止时刻。技术安排不改变出示规则，凡程序令已定"演示材料须提前 N 天提交"，远程不豁免。
6. **盘问提纲**：按仲裁员阅读顺序排列（争点 → 该争点的关键文件 → 文件页码 → 要证人确认的一句话），不按证人笔记本的时间顺序。每问先给出处再发问，封闭式问题为主；列出可能被对方以"无基础"拦下的问题并准备替代措辞。证人本人的陈述与其引用文件必须逐页复核，同一事实多份陈述的日期口径先自查统一。
7. **证人询问流程执行口径**：己方主问限时、只补陈述未涵盖的必要事项，不重述全文；对方盘问时按异议口径处理（见下条）；仲裁庭提问时间预留，防止己方证人被压缩；专家询问与专家会议（含并列询问）按 `08-evidence` 定下的机制执行。
8. **异议口径**：反对只说法定理由类别（超出陈述范围、无基础、与可信度无关、已回答、复合问题、要求猜测）+ 一句事实依据，不作论辩；被驳回立即继续，不缠讼；把每次被不当限制的提问记入用时表与纪要，为后续正当程序主张留痕（铁律 7：同时预判仲裁庭关注点——比例、平等、时间表压力，多数时候仲裁庭宁愿事后限制证明力而不打断询问）。
9. **开场陈述**：以争点为轴、以证据编号为锚；一条主线首尾重复；每节开头一句说明接下来讲什么；己方弱点主动交代并给解释框架，抢在对方之前；明确列出仲裁庭必须回答的问题；每个论点指向一份核心证据及编号但不逐条念；不引入任何新证据或新请求；承诺范围不超过证人实际能证的内容——开盘问后落空即变成反证；结尾回到请求主文。被申请人用数字框架（"三个争点"）收敛议题，每点先复述对方断言再指出与之矛盾的原始文件。
10. **结案陈词**：把证据回接到法律要件，形成"规则章 + 适用章"的可抄写链条；每个争点收尾给出证据指向（关键问答 + 庭审记录页码）；不利证据正面处理并说明其法律意义；备位论证（即使认定责任，金额亦应限于…并给出可采数字）；指出对方未证事项，逐条列举其举证缺口；请求主文与开场陈述一致，不得在结案时新增；费用单列一节，依据写对方的程序行为而非仅结果。不允许口头结案时，按指定页数与日期交书面最终意见并逐条回应仲裁庭归纳的问题。
11. **仲裁庭初步非约束性意见**：请求须双方联署或正式入卷，并明写"不作任何争点的结论、不影响裁决"；回复严格区分"接受商业框架"与"不放弃法律立场"，不得在其上放弃权利或承认原本未认的事实；把和解窗口与"不和解即恢复程序"的自动时间表一并写入记录；若据其达成和解，转 `10-award-post` 核验仲裁庭权限、程序状态、当事人同意及适用法／规则条件，比较和解协议、合意裁决及符合条件的调解／合同执行路线；由 `14-cross-border-enforcement` 逐目标地核验适用范围、形式及排除条件、成本与执行障碍。普通和解不自动成为裁决或调解执行文书，合意裁决也不保证消除原有执行障碍；不保证或否定任一路线，未核验事项标 `待核验` 并登记来源与核验任务，不为取得新裁决先释放既有权利。
12. **庭后简报**：标题逐字复制仲裁庭问题，问什么答什么、顺序一致，子问 (i)(ii)(iii) 小标题逐一作答；每节先两三句结论再展开；一切主张挂记录页码，关键问答逐字引用加脚注；页数是硬约束，细节进附表与脚注；只处理庭上已出现或庭方提出的问题，需补新法律或新文件必须先申请许可并说明为何庭前无法取得；数字争点按输入项逐一处理（对方取值—理由—正确取值—影响金额）；结论段与可抄写的裁决主文一一对应；无问题清单时自行归纳争点并请仲裁庭确认。
13. **费用陈述与对对方费用的异议**：己方按类别出分项账单（机构费／仲裁员费用分摊／外部律师费／专家费／差旅／速录口译／场地），每类可回溯到凭证与账单明细，计费期间切分为仲裁前·仲裁中·庭审期·裁决后，标注每位出庭人员姓名与角色，金额折算为裁决币种并注明汇率时点与利息起算。内法务时间与员工证人工资性时间一般不可偿（需论证外部替代成本）、同一人不得既作事实证人又按专家标准计费——这两点是对方最常打的突破口，先自查。异议对方费用时逐项目号逐句对应、用己方可比数据（总小时、平均费率、出庭人数）形成数量级对照、必要性优先于单价、角色错配逐一指出、限于费用问题不重开实体、给出建议扣减额；勿指向机构已核定的费用（超出仲裁庭权限），并在指定期间内提交，逾期视为放弃。
14. **纪要与不利记录**：庭审当日核对出席名单、证人出庭与盘问顺序、用时消耗、被驳回或被限制的提问、任何口头承诺；对方或仲裁庭口径进入纪要而与事实不符时，在订正期内提出书面纠正并附记录页码，不当日提出即视为默认。不利记录（己方承认、承诺的时限、被排除的材料）逐条登记并评估其对裁决与撤销程序的影响，需修补的在庭后简报中按问题处理，不另函辩解。

## 四、常见错误

- 用天数而非小时做时间分配，一方以整日占用，己方证人被压缩。
- 演示材料庭上才发，被排除；开场或结案引入新证据新请求，被指突袭甚至重开庭。
- 预读函写成微型结案陈词，或段落号与卷宗页码错位，或漏抄送对方。
- 未扣仲裁庭提问时间、无平等用时记录，事后被指违反平等原则。
- 盘问要点或证人名单逾期提交，被禁传该证人。
- 开场过度承诺证人所证内容，盘问后落空变成对己方不利的反证。
- 结案大段复述证据而不做归摄，仲裁庭无法抄用；回避对方最强论点被视为默认。
- 把庭方的暂定意见当胜诉保证而拖延，或在回复中不小心承认事实；未核验庭权与目标地条件就强制转合意裁决，或断言和解协议没有独立执行路线。
- 庭后简报超页、复述开场、漏答子问、改写记录原话被指引用不准。
- 费用清单只有总额无凭证，被按"无法判断合理性"整体打折；借费用异议重辩实体，整体不予考虑。
- 未约定口译与笔录费用归属，庭后为账单再起争议。
