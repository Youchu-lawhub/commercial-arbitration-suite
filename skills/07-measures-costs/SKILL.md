# 临时措施、紧急仲裁员与费用担保

本文件处理程序性救济与费用安排；按已核适用标准组织申请或抗辩，不预置跨法域统一门槛。

## 一、入口闸门

材料要求以 `suite.yaml` 的本子技能条目为唯一依据。已在会话中明确的事实直接登记，不重复索取。
对实际案件，先核对本案配置，再把已读取的材料逐项登记到案件根 `case.json`（`rulesuite-case/1`）；台账 `case` 与配置一致，Markdown 清单仅由台账生成供人阅读。

```bash
python3 <suite>/scripts/route.py --gate 07-measures-costs --profile <文书类型> --workdir <案件目录> --provided <案件目录>/case.json
```

本子技能任务类型：`interim`、`security`、`advance`。只选本轮需要的文书类型，不把其他类型的必填项合并进来。

未通过时，针对影响本轮结论的缺项提问；可先整理已知事实、检索路径与明确标为未完成的框架，不虚构事实，不交付未核验定稿。通用教学或规则导航问题不要求伪造案件配置。

## 二、动作

- 先提醒紧迫窗口，再承接当前事实、程序状态、措施对象及缺口；分清财产保全、证据保全、行为保全、费用担保与预缴，不把下述要件示例当跨法域统一门槛。
- `interim` 用 `measures.target` 登记措施对象、所求保护与依据。财产措施核查具体财产及责任，证据/行为保全围绕证据、现场、行为与不可逆后果取材，不强迫用户提供无关资产；未知部分仍列缺口，不假勾已确认。
- 财产保全/担保涉及资产时逐项核主体、权属、所在地、用途、负担与可处分性；集团成员、母子公司、担保人分别核责任和控制依据，不把集团资产当债务人资产。
- 国家、国企或主权基金逐项核主体属性、商业/公共用途、管辖豁免、措施/执行豁免、放弃条款及适用范围，不因仲裁同意自动推定放弃执行豁免。
- 措施可执行性、目标 T 及权属调查交 `14-cross-border-enforcement`，法源与法院协助交 11，证据取得交 08；T 主表只在执行矩阵，已有 case 矩阵仅引用并同步相关事实/救济。
- 提交前留存对方最强反驳、仲裁庭/法院关注点与残余风险；同人自审标 `self_review`。未实际批准、缴费、送达的动作仍记待办。

1. **先定救济路径**：仲裁庭已组成 → 向庭申请；尚未组成且需要组庭前救济 → 现查本案适用规则版本是否设有紧急仲裁员/组庭前程序及其**适用条件与排除情形**（部分机构机制可被条款约定排除、部分条款订立于机制引入前的案件不适用、临时仲裁无内置机制），条号与费用条件一律现查：
   ```bash
   python3 <suite>/scripts/fetch_official.py lookup <规则版source_id> --pattern "emergency|interim|conservatory|provisional" --max 12
   ```
   同时核三项失权要点：申请费/押金未缴可否被径行驳回、决定作出后的失效期、失效前必须推进主案的衔接。禁止凭记忆写"某机构有/没有紧急仲裁员"。
2. **法院协助可行性四维核验**（只作程序判断，实体口径转 `skills/11-governing-law` 并按来源分层标注置信度与需外部律师意见，铁律 6）：① 仲裁地法是否授权仲裁庭/紧急仲裁员采取措施、以何种形式；② 仲裁庭措施能否由当地法院执行、是否须先向庭提出方可向法院申请；③ **资产地/履行地**是否与仲裁地不同，因而需在资产地单独申请当地保全；④ 当地法是否要求法院发出临时命令后限期启动仲裁或与仲裁程序联动。检索起点见 `references/asia-jurisdictions.md`；该文件只列问题与来源通道，具体结论须运行时以官方文本核验并留存来源标记。
3. **按本案适用标准分节举证**（模板 `assets/templates/07-interim-measures.md`），先核哪些是必要要件、裁量因素或不适用项，再逐项附用户材料锚点；下表仅为问题线索：
   | 待核因素 | 论证要点 | 证据锚点从何处取 |
   |---|---|---|
   | 表面权利或请求基础 | 核所需证明程度，不预断实体 | 合同与条款、通知及回复、履约与验收记录 |
   | 紧迫性 | 时间窗口、无法等待通常程序的原因 | 行为时间戳、知悉日、申请日、现场或系统变更记录 |
   | 损害或证据灭失风险 | 核是否要求不能充分以金钱补偿及具体标准；证据保全单独核必要性 | 不可恢复后果、证据保管和删除期限、追索障碍材料 |
   | 比例性、利益衡量或其他因素 | 最小必要范围、双方和第三人影响、可替代保护 | 成本测算、对等承诺、监督安排、第三方依赖 |
   不用主案违约事实替代措施所需证据，也不要求不适用的要件。
4. **措施主文的可执行性纪律**：明确义务人、对象、可控行为、现状基准、期限及验证标准（如恢复指定场所通行而非笼统写不得妨碍）。先核各主体是否受仲裁协议约束，不向未经确认受约束的第三人请求仲裁庭命令。银行、登记机关等的协助权限与法院路径另核；保函争议分别核对相对人的行为约束、银行付款机制和法院止付条件，不把一条路径的命令当另一条路径当然可执行的依据。转 `11-governing-law` 研究并与 14 衔接。
5. **提出可实施的措施方案**：附拟议主文、必要的替代方案与程序安排。只有涉及款项时才列监管账户、币种、金额、支取条件等；证据或行为措施围绕保存、访问、监督和恢复安排。反担保、赔偿承诺或提存须有依据并取得用户授权。涉及先行付款或近似终局效果时，核是否有特别权源、相应门槛与替代措施，不预判必然被拒。
6. **对对方措施申请的抗辩**：按已核标准逐项回应管辖、权利基础、紧迫性、损害或证据风险、比例性及第三人影响；用时间线与证据解释迟延和现状，避免只说没有违约。备位请求缩小范围、缩短期限、担保或复核。取得决定后，提取实际理由及再申请、变更或撤销条件；核是否需要情势变化或新证据，不把所有二次申请一律限定为同一门槛。对不利事实归纳按允许的程序及时回应，期限与救济路径另核。
7. **担保费用：申请侧**（模板 `assets/templates/07-security-for-costs.md`）：先取得适用规则、仲裁地法及相关决定，确定权限与标准，不把胜诉可能和无力偿付预设为统一的两项门槛。按该标准论证费用裁决不获清偿的实际风险、财务困难成因与时间、当事人行为、比例性及对诉权的影响；己方造成对方困难可能构成反对担保的理由，不能反向当作当然有利因素。逐项附财务报表、审计意见、清算/重整、资产处分及既往履行记录；集团联系或资助存在本身不证明可清偿。预算给区间、阶段、费率与凭证，提出规则允许且可落实的担保形式、期限和不履行后果，不混同标的保全。
8. **担保费用：抗辩侧**：明确谁申请担保、谁被要求提供担保，再针对本案标准与材料回应。核我方财务困难是否由申请担保方行为造成、缔约时风险是否已知、可用财产或有约束力的支持是否足够、担保是否妨碍实质行使请求权、金额是否过高；实体强弱仅在适用标准允许时论证。第三方资助须核是否覆盖败诉费用及承诺可执行性，不能仅因有资助即否认清偿风险。备位提出金额、形式、期限、释放条件与有依据的计息安排；保密或披露异议说明具体依据及替代证明，不无条件拒绝必需披露。
9. **预缴款与费用杠杆**（模板 `assets/templates/07-advance-on-costs.md`）：先核机构催缴、替代缴纳及不缴后果，向用户说明资金需求与继续程序的选择；实际垫付后留存凭证。核仲裁庭是否有权命令偿还、何时可以申请、以命令或裁决作出及是否可获执行，不因名称为 award 即认定满足《纽约公约》条件，也不因名称为 order 即排除当地法的其他执行路径。利息仅按已核合同或法律依据请求，不预置参考利率或利差。中止、视为撤回、分请求处理等后果按适用规则纳入时间表；税项、代扣、付汇及发票另向用户财务和必要的专业顾问核实。
10. **第三方资助**：现查适用法、规则、程序令及机构指引，核披露存在、资助方身份、利益关系、协议条款的范围、时点与持续更新义务；不得预设身份可不披露。对超出必要范围的商业条款或特权材料，可依法申请遮蔽、保密或限定披露，不遮蔽必须披露的信息。资助是否覆盖败诉费用、资助方控制权及退出条件按实际材料分析；资助成本可赔性须单独核权源、标准与裁量因素，不作统一允许或禁止结论。
11. **费用分担主张框架**：从程序早期即建立可赔性台账（阶段、事项、费率、凭证、币种），最终费用陈述按"可赔范围—合理性—比例—行为不端的费用后果（迟延、拒不披露、不缴预缴款、过度申请）"四层展开；程序性申请阶段主动请求"本阶段费用留待最终裁决一并处理"，避免被裁令即时承担。庭后正式费用陈述转 `assets/templates/09-post-hearing.md`。
12. **对置检查**（铁律 7）：措施申请、措施抗辩、担保申请、担保抗辩、预缴裁决请求五项，各写一行"对方最可能的反驳 + 仲裁庭的关注点"（如：措施被视为主案实体预判、担保被视作接近拒绝司法、命令被视作无法执行），删除单方乐观结论；并提示此类程序性决定的单独救济空间有限，须在最终裁决的正当程序抗辩中保留主张（转 `10-award-post`）。
13. **交付配对**（铁律 5）：
    ```bash
    python3 <suite>/scripts/render_docx.py --in <draft.md> --out <draft.docx> --mode legal
    python3 <suite>/scripts/verify_suite.py --workdir <案件目录> --mode submission
    ```

## 四、常见错误

- 未核适用标准便照搬统一四要件；仅说会受损而不证明本类措施所需风险。
- 未核主体约束与权限便请求命令银行、登记机关或其他第三人。
- 未核特别权源便用临时措施实现终局效果，或不评估更小范围的保护。
- 凭记忆写紧急仲裁员的天数、费用与适用条件，或忽略条款已排除该机制。
- 以"对方是外国公司/规模小/子公司"作为担保费用唯一理由；估算虚高；未附己方费用预算。
- 仅凭 order/award 名称判断执行力，或未核催缴、垫付和偿还的条件。
- 用临时措施被驳回后贸然向法院平行申请，未先评估规则与法院关系。
- 仲裁地措施当成资产地可执行；执行地路径未同步核验。
