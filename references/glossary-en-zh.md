# 仲裁术语中英对照 Glossary (EN–ZH)

> 使用定位：本文件是方法与检索线索，不是已核验的本案法律依据。机构版本、条号、期限、金额、站点及 MCP 状态须在使用时回到官方文本和本机能力复核；无法核验的具体结论不得直接写入定稿。

## 阅读导航

- 一、程序主体与文书
- 二、管辖与可受理性
- 三、启动与答辩
- 四、组庭与仲裁员
- 五、临时措施与费用
- 六、证据与庭审
- 七、裁决与善后
- 八、易混词对照
- 九、使用与核验纪律

> 用途：起草英文文书、撰写配套《中文审阅说明》、向涉外法务解释程序概念时取用通行译法。它防的是两类具体错误——中文译名错（把 security for costs 写成"财产保全"）与英文用词错（把可受理性问题写成 jurisdiction objection，等于替对方承认管辖）。
> 这不是学术词表：只收本套件文书与子技能里真正会落笔的词，每条一句诊断，不展开制度沿革与学说争议。
> 列格式：`英文术语 | 中文通行译法 | 程序功能与常见误用`。《中文审阅说明》里的术语表用同一三列格式，一份说明只摘本案实际出现的数条，不整表粘贴。
> 数字纪律：本表不载任何规则版本相关的天数、金额门槛与条号。凡出现 `[[以适用版本官方文本核对]]`，须按 `references/forum-rules-matrix.md` 的核验流程，用 `scripts/fetch_official.py applicable --inst <机构> --commencement <启动日>` 定版本，再 `lookup` 命中该版本文本后方可写入文书（套件铁律 1、2）。
> 范围纪律：只收涉外商事仲裁用语；纯境内商事仲裁与劳动争议用语不收。为向中国读者解释差异而写的对照，一律以「境内对照：」标出，只作差异提示，不作境内制度结论。
> 译名纪律：同一文书内同一术语固定一个中文译法；机构名、规则名、书状名、程序令编号保留英文原名，首次出现时括注中文，不自创别名，也不把英文句式硬译成境内诉讼文书套语。
> 八组：程序主体与文书／管辖与可受理性／启动与答辩／组庭与仲裁员／临时措施与费用／证据与庭审／裁决与善后／易混词对照。

## 一、程序主体与文书

| 英文术语 | 中文通行译法 | 程序功能与常见误用 |
|---|---|---|
| arbitral institution | 仲裁机构 | 依规则管理程序的机构，与作出裁决的仲裁庭是两个主体；把 "the institution" 译成"本庭"会让当事人把函件发错收件人。 |
| arbitral tribunal | 仲裁庭 | 个案组成、案结即散的裁判主体；中文"法庭"是错误译法，"the Court" 在机构语境还可能指机构委员会而非仲裁庭。 |
| secretariat / registry / registrar | 秘书处／登记处／登记官 | 机构的行政与收发机关，负责收件、起算期限、组庭与费用核定；受理与管辖审查的关系须按适用规则核对，不得把收件当作管辖认可。 |
| administrative council of the institution | 机构委员会（任命与决定机关） | 负责任命仲裁员、决定管辖初裁、批准裁决草案的内部机关；写"the Court"而不加机构名时，仲裁庭默认理解为国家法院。 |
| ad hoc arbitration | 临时仲裁／非机构仲裁 | 无机构管理、靠当事人与任命机关推进的程序；与"临时措施"毫无关系，与"约定由机构指定任命机关"也不矛盾。 |
| institutional rules | 机构规则 | 当事人约定适用的程序规则，性质上属合同条款；与仲裁地强行程序法分层，效力、修改与违反后果都不同。 |
| lex arbitri / curial law | 仲裁地法／程序准据法 | 仲裁地国仲裁法，决定法院介入、撤销事由与可仲裁性；不是合同准据法，也不是机构规则，三者混写会在撤销阶段被对方利用。 |
| seat / place of arbitration | 仲裁地（法律意义） | 决定仲裁地法与裁决国籍的法律坐标；开庭城市、机构所在地、己方办公地都不是 seat，境内对照：与诉讼法上的"管辖法院所在地"也不是一回事。 |
| award | 裁决 | 仲裁庭就请求、费用等作出并具备终局拘束力与可执行性的裁定；程序性处理写成 award 会抬高形式要求，反之则丢执行路径。 |
| decision | 决定 | 处理程序争点的判断，通常不具备裁决形式与公约执行力；把 decision 译成"裁决"会误判救济与执行窗口。 |
| order / procedural order | 命令／程序令 | 仲裁庭管理程序的指令（含程序令第 1 号）；金钱给付若只以 order 作出，执行阶段可能无从依公约申请。 |
| direction | 指示 | 程序令中较轻的行为要求；英文文书里 "orders" 与 "directs" 并列时中文应分别写"责令"与"指示"，不要合并成"要求"。 |
| terms of reference | 任务书（争点与请求范围确认书） | 界定当事人请求与争点范围的锚文件，未在其中保留的请求其后追加须经仲裁庭乃至机构同意；与专家的 terms of reference 同词不同义。 |
| case management conference | 案件管理会议 | 组庭后一次定妥书状轮次、页数、披露制度与庭审日期的会议；不是调解会，会上表态仍受保留权利条款约束。 |
| procedural timetable | 程序时间表 | 由程序令固定的各节点日期；它是当事人合意或庭定期间，与规则法定期间不同，起算口径与顺延基准要逐格写明。 |
| minutes of the hearing | 庭审纪要 | 记录出席、用时、顺序与口头承诺的程序文件；与逐字笔录性质不同，不能用来引证人原话。 |
| transcript | 逐字笔录／庭审记录 | 庭上问答的逐字记录，是庭后简报引用原话与主张提问被不当限制的唯一坐标；速录与录音不是同一物。 |
| legal authorities | 法律引证材料 | 提交给仲裁庭的判例、条文与学理文献；约定页数上限时须明示是否计入，否则会被以超页删减。 |
| submissions | 书状／意见（书面或口头） | 泛指提交给庭的论证文件与口头陈述；译成"提交物"或"申请材料"会失去其论证性质，也可能与 exhibits 混淆。 |
| power of attorney | 授权委托书 | 证明签署人与代理人程序权限的文件，须逐项覆盖提名仲裁员、签署任务书、提出与回应请求、和解、收款、申请临时措施与执行等权能；缺项即可能在签署时被要求补正而吃掉期限。 |
| counsel / external counsel | 代理人／外部律师 | 涉外仲裁中的代理身份不以境内执业律师为限；把 "counsel" 一律译"律师"会掩盖机构对代表人变更的披露与限制要求。 |
| ex parte / unilateral application | 单方（未通知对方）申请 | 指未先行通知对方即提出的程序，如部分法域的单方执行许可；不等于"缺席"，也不等于"一方陈述即定案"。 |

## 二、管辖与可受理性

| 英文术语 | 中文通行译法 | 程序功能与常见误用 |
|---|---|---|
| jurisdiction (of the arbitral tribunal) | 管辖权（仲裁庭的裁判权限） | 仲裁庭据仲裁协议对争议作裁判的权限；境内对照："管辖"在境内法语境还兼指法院之间与级别分工，翻译时须先确认指的是仲裁庭权限。 |
| competence-competence | 自裁管辖权 | 仲裁庭有权裁自身管辖，包括否定管辖；它不意味着该裁断终局，多数法域仍允许仲裁地法院事后审查。 |
| prima facie | 表见（表面成立） | 机构在受理阶段只作"是否明显无管辖"的浅层判断，不影响仲裁庭最终裁断；译成"初步证据"会被误读为实体举证标准。 |
| admissibility | 可受理性 | 请求是否适合在本案程序中处理，典型是时效经过、前置磋商条件未成就、请求尚未成熟；它不是"有没有管辖"，写成管辖异议反而可能被援引为接受管辖。 |
| objection to jurisdiction | 管辖权异议 | 对仲裁协议是否存在、有效、涵盖本案争议及当事人是否受拘束的异议；须在规则规定的最早阶段提出，迟延即有弃权风险。 |
| objection as to scope (excess of scope) | 超范围异议 | 请求落在条款文义之外，与"仲裁庭无权"是两条线；多数规则要求此类异议一出现即立即提出。 |
| separability | 仲裁条款自治性 | 主合同不成立、无效或终止不当然使仲裁条款失效；中文"独立性"与仲裁员独立性（independence）撞词，两者必须分别用词。 |
| arbitrability | 可仲裁性 | 争议依仲裁地法（及执行地法）可否交由仲裁解决，与公共政策邻近；属裁决后无法补救的缺陷，条款阶段就要核。 |
| personal scope / non-signatory | 人的范围／非签署人 | 集团架构、加入关系、承继下谁受条款拘束；"我方非签约方"是管辖层抗辩，不是实体抗辩，写在实体段会自降强度。 |
| condition precedent to arbitration | 仲裁前置条件 | 多层条款中协商期、调解期是否成就及其期限；未成就的抗辩多被归入可受理性，也有法域按具体情况定性，须分法域写。 |
| governing law of the contract | 合同准据法 | 规制实体权利义务、违约责任与时效的实体法；与仲裁协议准据法分节陈述，合并写会诱发"只选了一次法"的解释。 |
| law governing the arbitration agreement | 仲裁协议准据法 | 规制条款存在、效力与范围的法律，可能与合同准据法、仲裁地法均不同；未明示约定时主张何种连接点要写清楚。 |
| renvoi / conflict of laws rules | 反致／冲突规范 | 选法条款常写 "excluding its rules of private international law" 以切断反致；漏译这一限定等于把准据法交回对方解释。 |
| mandatory rules / overriding mandatory provisions | 强制规则（直接适用规范） | 不问准据法为何均须适用的规则，会影响效力、可仲裁性与执行；不是"任意性规范"的简单反面。 |
| public policy / ordre public | 公共政策 | 执行端与撤销端的兜底审查口径，各国宽窄差异大；不能等同于"违反某国法律强制性规定"，须按执行地现查并标注需外部律师意见。 |
| stay of proceedings | 中止程序 | 法院中止诉讼以移交仲裁，或仲裁庭暂停主案等待其他程序；与终止（termination）必须严格分译，混用会改变是否已决的判断。 |
| lis pendens | 未决（平行）程序 | 同一当事人同一争议已在其他程序未决，用于阻止平行推进；与已决（res judicata）方向相反，写反即整段论证失效。 |
| wasted costs | 无谓支出 | 因分叉审理、被驳申请或程序重置而徒增的费用；须在主文中单列请求，否则只按整体结果粗略分担。 |

## 三、启动与答辩

| 英文术语 | 中文通行译法 | 程序功能与常见误用 |
|---|---|---|
| Request for Arbitration / Notice of Arbitration / Application | 仲裁申请书／仲裁通知／仲裁申请 | 各机构对启动文书的命名不同，且起算点分别挂在机构收件、对方收到或副本送达；引用时保留该机构原名，不自行统一为"仲裁通知"。 |
| commencement of the arbitration | 程序启动时点 | 决定时效是否中断的关键点，口径可能是发出、送达、视为收到或机构收件；届满与起算的具体规则一律 `[[以适用版本官方文本核对]]`。 |
| limitation / prescription / time bar | 时效（消灭时效／请求权时效） | 准据法上的实体期间抗辩，效果可能是请求权消灭或抗辩权发生；与程序期限（time limit）不同层，境内对照：中文"诉讼时效"只对应这一层。 |
| time limit | 程序期限 | 规则或程序令确定的提交期间，可依法或依庭指示延展；译成"时效"会把可延展的程序期间说成失权的实体期间。 |
| Answer to the Request for Arbitration | 对仲裁申请的答辩（答辩书） | 对启动文书的正式回应，承担人数与提名表态、管辖异议、逐条对应三重功能；境内对照："答辩状"是诉讼文书名，涉外交付宜用"答辩书"并保留英文原名。 |
| statement of claim / statement of defence | 请求陈述书／答辩陈述书 | 程序令确定的首轮实体书状，与启动文书、答辩文书不是同一份文件；混用会低估任务书签署后变更请求的门槛。 |
| memorial / counter-memorial / reply / rejoinder | 申诉书状／答辩书状／反驳状／再答辩状 | 书状序列的阶段性名称，交换顺序有单案差异；写成"上诉状""再审申请书"式译名会误导当事人以为可层级上诉。 |
| counterclaim | 反请求 | 被申请人向申请人提出的独立请求，须自足并落在同一仲裁条款范围内；境内对照："反诉"是诉讼法概念，费用与受理条件不同，不宜照搬。 |
| set-off | 抵销（以抵销为抗辩） | 以互负到期同种给付义务抵销对方请求；有的制度把它当独立请求、有的当抗辩，是否并入争议金额计算直接影响费用档级。 |
| cross-claim | 交叉请求 | 多当事人程序中一方向其他被申请人（而非申请人）提出的请求，主体方向与反请求不同，写错即请求对象错误。 |
| joinder | 追加（非当事人为）当事人 | 把案外主体并入既存程序，截止点常在仲裁员提名或任命之后，逾期后实务中极难获准；境内对照：与有独立请求权／无独立请求权第三人不是同一制度。 |
| consolidation | 合并仲裁 | 将已分别存在的数个仲裁合并为一个程序，通常由机构在累积要件下决定，且已组庭时受限；与"多合同并于一案"不是同一机制。 |
| multiple contracts in a single arbitration | 多合同于一案审理 | 依数份仲裁协议在同一程序中处理关联合同，要件各机构不同；条款阶段不一致的机构、seat、人数与语言会直接堵死这条路。 |
| admitted / denied / no admission made | 承认／否认／不作承认 | 逐条对应的三种状态；"不作承认"用于我方尚无信息且不愿推定事实的行，沉默回避某项管辖或事实问题事后可能被认定为接受。 |
| reservation of rights | 保留权利 | 声明参与某项程序或同意某项安排不构成对管辖、弃权或实体立场的表态；漏写会被对方主张既成事实。 |
| without prejudice | 不损害权利（磋商内容不得援引） | 指该通信不得在实体阶段被援引为承认，不等于"与争议无关"，也不是任何标注该词的函件都自动不可采。 |
| waiver / estoppel | 弃权／禁止反言 | 明示或以行为放弃权利；普通法 estoppel 的外延与中文"禁反言"不完全重合，重要场合保留英文并括注。 |
| leave / permission of the Tribunal | 仲裁庭许可 | 追加请求、开启第二轮书状、延期等须先取得许可；未获准不得推定"沉默即同意"，申请要附明确期限与理由。 |
| extension of a time limit | 期限延展 | 对规则或程序令期间的延长请求，应一次给足具体届满日并说明规模与复杂性；反复追加损害合作性评价。 |
| default of participation / award in default | 未参与程序／缺席情况下的裁决 | 一方不应诉或不出现不阻却组庭与程序推进；与合同语境下 "event of default"（违约事件）同词不同义，须在同一文书里分译。 |
| service of documents / proof of despatch | 送达／发送凭证 | 起算点常取决于送达或视为收到而非发出，故送达路径、地址来源与发送凭证须逐案留存。 |
| deemed received / date of receipt | 视为收到之日／实际收件日 | 期间起算的法定拟制与实际签收可能不一致，时限日历应同时登记两者并写明采用哪一个及其条文依据。 |

## 四、组庭与仲裁员

| 英文术语 | 中文通行译法 | 程序功能与常见误用 |
|---|---|---|
| nomination | 提名 | 一方提出己方仲裁员人选的意思表示，效力取决于期限内提出并附齐必载信息；提名不等于该人选已就任。 |
| appointment / designation | 任命／指定 | 使仲裁员就任的行为，可能来自当事人、机构、任命机关或其余仲裁员；与提名混写会掩盖机构确认环节。 |
| confirmation | 确认 | 机构对当事人提名的核验权力，未获确认即不生效；机构可依规则迳行代指，故己方内部响应期限要按代指触发日倒排。 |
| co-arbitrator | 当事人各自提名的仲裁员（边裁） | 与首席相对的两名仲裁员；"副仲裁员"是错误译法，"co-arbitrator" 也不可写成 "co-claimant"。 |
| president of the Tribunal / presiding arbitrator | 首席仲裁员／仲裁庭主席 | 三人庭的主持者；机构内设机关的主席英文亦作 chairman，指代不明时读者会误认为机构人员。 |
| chairman (of the institution) | 机构（委员会）主席 | 机构层面的负责人，可代当事人或仲裁员作出任命；与首席仲裁员是两个角色，混译会造成任命主体错误。 |
| sole arbitrator | 独任仲裁员 | 一人庭；不要与 "sole" 的其他含义（唯一、单独）混淆，也不要在三人庭约定下擅自使用。 |
| umpire | 公断人（第三人） | 旧式两条仲裁员加一公断人的结构用语，多见于旧条款与旧法域；遇旧条款应保留原词并解释其转任主席或独任的机制。 |
| appointing authority | 任命机关 | 无机构管理时补足任命僵局的主体，条款必须写明，否则陷入僵局；机构名写错或指向不存在的机关是病态条款的高频形态。 |
| list system / strike-and-rank | 名单勾剔制 | 由机构提供候选名单、双方排序删除的任命方式；回复期极短，内部响应时限须短于该期，天数 `[[以适用版本官方文本核对]]`。 |
| statement of acceptance, impartiality and independence | 接受任命、公正与独立声明 | 就任前出具的三合一声明，是披露审查的起点；中文常漏译 acceptance，导致后续以"未接受任命"为由的挑战被误读。 |
| disclosure statement | 披露声明 | 列明可能影响独立与公正的具体事实；抽象的"无利益冲突"表态在挑战程序中几乎没有价值，评估时要把事实时间轴化。 |
| continuing disclosure duty | 持续披露义务 | 贯穿程序始终的更新义务，新任命的关联、新发生的关系都要披露；只在就任时披露不构成完整履行。 |
| justifiable doubts | 可正当怀疑（存在偏私或利益） | 采客观第三人视角，问"该怀疑是否正当"，不问"是否确有偏私"；中文"合理怀疑"带刑事证明色彩，宜写"可正当怀疑"并保留英文。 |
| independence | 独立性 | 仲裁员与当事人、代理人之间无上下、经济或从属关系；与公正性不同层，只主张其一而不给事实切割，挑战易被驳。 |
| impartiality | 公正性 | 对争议结果与双方立场的态度；"法律观点不合我方预期"属主观不满，不构成公正性事由，混入即削弱整体可信度。 |
| challenge (to an arbitrator) | 对仲裁员的挑战（异议）申请 | 依规则请求决定仲裁员去留的申请，须在规则所定期限内书面提出并由规则指定的机关决定；期限与决定机关一律 `[[以适用版本官方文本核对]]`。 |
| disqualification | 回避／取消资格 | 挑战成立的结果，指该仲裁员不得继续任职；与辞任、替换是三个不同环节，写在同一句里会造成因果倒置。 |
| replacement / substitute arbitrator | 替换（补位）仲裁员 | 空缺后的继任任命，可能触发组庭重组与已进行程序是否重开的问题；多方程序中追加当事人会放大该风险。 |
| resignation | 辞任 | 仲裁员主动退出，机构或庭可决定是否接受并就费用与程序后果作出指示；不等于对异议的承认。 |
| qualifications agreed by the parties | 当事人约定的仲裁员资格 | 条款约定语言、行业、法域经验等资格；资格不符与独立公正是两条线，前者对应组庭不符约定的撤销事由。 |
| dissenting opinion | 不同意见 | 仲裁员个人不同意见，能否随卷取决于规则与仲裁地法；它可能是撤销阶段的救济素材，也可能是对方弹药，先定性再引用。 |
| mandate | 委任（任期） | "continued mandate" 指继续任职；译成"授权"会与授权委托书混淆，译成"任期"则不适用于个案委任。 |

## 五、临时措施与费用

| 英文术语 | 中文通行译法 | 程序功能与常见误用 |
|---|---|---|
| interim measures / conservatory measures / provisional measures | 临时措施／保全措施／临时保全措施 | 三个英文分属不同文本传统，实质相近；决定形式（以 order 还是 award 作出）才真正影响可执行性，翻译时保留原词并括注。 |
| emergency arbitrator | 紧急仲裁员 | 组庭前受理并作出临时性决定的仲裁员；机制是否可用、能否被条款排除、旧协议是否适用须现查，禁止凭记忆写"某机构有无"。 |
| emergency decision | 紧急仲裁员决定 | 通常具临时效力并设有失效期，失效前必须推进主案；译成"紧急裁决"会让人误以为可直接依公约执行。 |
| asset preservation / freezing of assets | 财产保全／资产冻结 | 多数法域下仲裁庭通常只能命令当事人不得处分，实际查封须由资产地法院执行；境内对照："财产保全"是法院裁定制度，不要写成仲裁庭可径行采取。 |
| attachment / garnishment | 扣押／第三人债权执行 | 针对特定资产的法院强制措施，仲裁庭对第三人（银行、买方、登记机关）无发令权；请求命令第三人会把整份申请的可信度拉低。 |
| security for costs | 费用担保 | 命令申请人就对方最终可能获赔的费用提供担保，属费用面救济，门槛通常同时涉及"我方很可能胜诉"与"对方无力偿付最终费用裁决"；不是财产保全，也不是预缴款。 |
| advance on costs / deposit | 费用预缴（押金） | 双方分担机构与仲裁员报酬的预付款，一方不缴时另一方可替代缴纳并请求以裁决形式返还；与费用担保混用会既误算金额又误引条文。 |
| filing fee | 立案费 | 启动阶段缴纳的费用，未缴可致不受理、档案关闭或起算动摇，直接波及时效主张。 |
| administrative charges | 机构行政管理费 | 机构收取部分，与仲裁员报酬分列，多数按争议金额从价；费率与档级为网站公布值，须记录取值日并实时核对。 |
| arbitrators' fees and expenses | 仲裁员报酬及开支 | 计时或从价，选择权常为限期档，须在阶段早期表态；税项与代扣要与预缴款分列科目，避免签署阶段出现资金缺口。 |
| amount in dispute | 争议金额 | 决定费用档级的计算基数；反请求与抵销是否并入、选择性请求、汇率取值日、连带责任是否重复计，均按适用规则现查。 |
| costs of the arbitration | 仲裁费用 | 一般含机构费、仲裁员报酬开支与当事人费用；主文须逐项写明，只写 "costs" 会留下结算争议。 |
| costs follow the event | 费用随程序结果负担（败诉方承担） | 以结果为基线的分配原则，须与实际胜诉比例、行为不当（迟延、拒不披露、不缴预缴）一并论证；它不是自动适用的规则。 |
| each party shall bear its own costs | 各方自负费用 | 与上述相反的结果，条款不写费用分配时该结果并非不可能，须在答辩与程序令阶段就表态。 |
| legal costs / representation costs | 律师费及代理费用 | 能否赔、赔多少由庭裁量；内法务时间与员工证人工资性时间一般不可偿，主张时须论证外部替代成本。 |
| submission on costs | 费用陈述（意见） | 庭后按可赔范围、合理性、比例、行为后果四层展开的书面意见；程序性申请阶段应同时请求"本阶段费用留待终局裁决处理"。 |
| lien on the award | 裁决留置 | 部分机构在全部费用缴清前不签发或不发副本，直接压缩执行窗口，须纳入裁决后日程。 |
| undertaking as to damages | 损害赔偿承诺 | 法院发布禁令时常要求申请人承诺措施错误时赔偿对方损失；仲裁庭措施通常不以此为条件，别把它当作申请临时措施的必附项。 |
| irreparable harm | 不可弥补的损害 | 指金钱赔偿不足以救济（保函兑付、许可失效、客户与订单流失、无法恢复原状），不是"我方会受损"；只论证权利而不论证此点是最常见驳回路径。 |
| balance of convenience / proportionality | 利益衡量／比例性 | 比较措施对双方的负担与不作为的后果，并说明对第三方与公共层面的影响；请求应写成最小干预版本，不必照搬普通法禁令公式。 |
| urgency | 紧迫性 | 指无法等待正常程序的时间窗，用行为的时间戳证据与"知悉日至申请日"的间隔证明；对方会用你自己的迟延反证。 |
| prima facie case / reasonable possibility of successful outcome | 表面权利成立／请求有合理胜诉可能 | 措施阶段仅作初步判断并明示不预断实体，不等于承认请求成立，也不构成对实体争点的决定。 |
| interim award | 中间裁决（以裁决形式的措施或先决判断） | 以裁决形式作出的措施或管辖判断，可执行性优于 order；"interim" 不等于 "partial"，前者强调临时效力，后者强调只裁部分请求。 |
| counter-security | 反担保 | 被申请措施一方以担保换取措施解除或缩范围；反向请求对方提供担保慎用，除非己方资信明显优于对方。 |
| third-party funding | 第三方资助 | 案外人出资支持程序并分享回报；披露范围与触发时点因规则而异，与保密条款并存须另设 carve-out，并用于回应或削弱费用担保申请。 |
| draft operative wording | 拟好的命令主文 | 措施申请中附上可直接执行的祈使句主文（对象、行为、期限、违反后果、可验证标准），大幅提高获准概率。 |

## 六、证据与庭审

| 英文术语 | 中文通行译法 | 程序功能与常见误用 |
|---|---|---|
| document production / disclosure | 文件披露 | 国际仲裁中的受限披露，由请求、异议、庭令构成；与美式 discovery 不同，把 "disclosure" 译"证据开示"会暗示可全面索取并招致负担抗辩。 |
| discovery / depositions / interrogatories / requests to admit | 美式证据开示／庭外录取证言／书面质问／要求自认 | 多数机构规则明文排除或不予支持，请求写法须改写为文件类别，而非照搬美式程序工具。 |
| Redfern schedule | 文件披露请求表（Redfern 表） | 逐条列请求、理由、异议、回应与庭裁的联合表；列数由庭规定，跨格引用（"see above"）等于空白。 |
| specificity | 特定性（具体事由） | 请求须指向可识别的主体、时段、文件类型与事实争点；出现"所有与本案有关的文件"式表述即退回重写。 |
| relevance | 相关性 | 与待决争点相连，须锚定到对方书状的具体段落号；只写"与本案相关"不构成相关性说明。 |
| materiality | 材料性（对结果的影响） | 缺少该文件会怎样影响结论；与相关性分两句写，合并成一句会被以"未说明材料性"驳回。 |
| possession, custody or control | 持有、保管或控制 | 说明为何相信被请求方握有该文件（其生成、其保存、关联方在其控制下）；未证此点的请求天然不足。 |
| adverse inference | 不利推定 | 一方未按令交出文件时，庭可就该文件内容作不利认定；须在程序令里事先写明逾期后果与推定依据，事后几乎无法主张。 |
| privilege / legal professional privilege | 特权（律师—当事人保密特权） | 拒绝披露的法定理由，须写明类型（为获取或提供法律意见／为可预见争议的准备）；中文常误译为"豁免"或"保密义务"。 |
| common interest privilege | 共同利益特权 | 多方基于共同法律利益共享法律意见时的特权基础，并非自动成立，须说明共同利益与范围。 |
| privilege log | 特权日志 | 逐条列文件类别、撰写人与收件人、日期与特权基础的清单；只写 "privileged" 的 blanket 主张应请求不予采纳。 |
| redaction / redacted version | 遮蔽／遮蔽版 | 隐去特权或敏感内容后的版本，须写明遮蔽范围与依据；把 redact 译成"修订"会造成版本与内容不一致的指控。 |
| attorneys'-eyes-only | 仅限代理人查阅 | 高保密档位，指仅对方外部律师可阅；须同时约定专家可否查阅，否则关键材料进不了专家报告。 |
| confidentiality order | 保密令 | 把双方谈定的保密条款升格为程序令后背书执行，违反会进入费用与证据评价；纯合同保密条款只能另诉。例外须逐字保留"履行法定义务／维护法律权利／执行或挑战裁决"三项。 |
| witness statement | 证人陈述 | 以证人名义签署、作为其主询问证据的书面证言，须区分亲历与转述；签署后不得补写新事实，需变化要出新版本并记录原因。 |
| affidavit | 宣誓书面陈述 | 境内法域证据形式，涉外仲裁中一般以证人陈述替代并辅以声明句；把 witness statement 译"宣誓书"会虚构不存在的宣誓程序。 |
| factual witness | 事实证人 | 就亲历事实作证；推测、评价语与"本案应如何裁决"一律删除，且不得与专家身份混用同一计费口径。 |
| expert witness | 专家证人（鉴定人式专家） | 就专业问题提供意见并对仲裁庭负首要义务；境内对照："鉴定人"由法院委托、制度不同，交付时宜写"专家"并保留英文。 |
| examination as to fact / evidence-in-chief | 主询问 | 以证人陈述为主要举证、庭上只补必要事项；不重述全文，超时由庭直接切断。 |
| cross-examination | 交叉询问（盘问） | 对方就陈述主题与可信度发问；"盘问"带刑事色彩，正式交付建议写"交叉询问"并括注一次。 |
| re-examination | 再询问 | 只限于盘问中新出现的事项，不得借机补充新内容，否则被以超出范围打断并计入用时。 |
| concurrent evidence / tribunal-led examination | 并列询问（庭主导的同堂询问） | 同领域专家或证人同时到庭、由庭主导讨论的机制；俗称 hot-tub 非正式，正式文书不写俗名。 |
| witness preparation / witness conferencing | 庭前准备证人／证人碰头 | 是否允许存在明显法域差异，须按程序令与仲裁地口径确认；指引文件属保密工作文件，不落卷、不含答案内容。 |
| terms of reference for experts | 专家职权范围 | 界定专家问题域、指定方式、报告交换、专家会与联合报告的清单；与案件任务书同词不同义，须加限定语。 |
| joint report of experts | 专家联合报告 | 报告交换后由专家共同出具，只列共识与分歧，不得在庭前由当事人统一口径。 |
| hearing bundle / core bundle | 庭审卷宗／核心卷宗 | 统一分页编号的合订材料，目录按争点分组并标注每份文件在何处被引用；"文件夹"式译名会丢掉编号体系的引用价值。 |
| exhibit / list of exhibits | 附件（证据）／证据清单 | 按连续序列编号并与正文段落互引，是庭后引用与核验坐标；已提交过的文件不要重复请求或重复提交。 |
| skeleton argument | 要点式口头陈述提纲 | 庭审口头陈述的结构提纲；与书面意见（written submissions）不同，不能借它引入新证据或新论据。 |
| opening / closing submissions | 开场陈述／结案陈词 | 开场不得引入新证据或新请求，结案须把证据回接到法律要件并形成可抄写的链条，主文与开场一致。 |
| post-hearing brief | 庭后简报 | 按仲裁庭问题逐条作答，标题逐字复制问题、顺序一致，一切主张挂记录页码；它是回答清单，不是第五轮书状。 |
| preliminary, non-binding view | 初步非约束性意见 | 庭在庭上或庭后给出的暂定商业框架意见，须双方联署或正式入卷并明写不影响裁决；不得在其上放弃权利或承认原本未认的事实。 |
| time allocation / equal time | 用时分配／平等用时 | 按小时而非天数分配询问时间并由秘书保存记录；译成"时间安排"会丢掉"平等对待"这一正当程序锚点。 |
| videoconference / hybrid hearing | 远程／混合庭审 | 连接方式与材料出示规则不因远程而豁免，演示材料截止日仍适用，各时区截止时刻须单列。 |

## 七、裁决与善后

| 英文术语 | 中文通行译法 | 程序功能与常见误用 |
|---|---|---|
| final award | 终局裁决 | 就提交给它的全部请求作出并终局拘束的裁决，是撤销与执行的主要标的；"final" 不等于"完整"，未决事项是否逐项保留要读原文。 |
| partial award | 部分裁决 | 就部分请求或先决问题作出、对该事项终局的裁决；每份裁决件各自单独起算撤销与执行期限，漏扫一份即漏掉一个窗口。 |
| jurisdictional award / award on jurisdiction | 管辖权裁决 | 先行处理管辖或可受理性的裁决件，形式为 order 时也可能须说明理由；是否可单独成为撤销标的要按仲裁地法现查。 |
| consent award / award on agreed terms | 合意裁决（依和解条款作出的裁决） | 把和解内容做成裁决形式才能依公约执行，只签和解协议在跨境执行上近乎落空；条款须用义务句式并配违约后果。 |
| award of costs | 费用裁决 | 单独处理费用分担与核定的裁决件，是独立救济与执行标的；机构已核定费用与庭方可裁费用须分别请求，不得重复请求超出权限事项。 |
| termination order | 程序终止令 | 结束程序但通常不是裁决，不能依公约执行；将来付款义务必须改走合意裁决，否则无从执行。 |
| date of the award / made the award | 裁决作出日 | 部分救济期限挂在作出日、部分挂在送达或收到日，两者混用会同时错过两条窗口，须先记日期再读内容。 |
| notification / dispatch of the award | 裁决送达（转交）日 | 机构转交与实际收到可能不同，庭签署日也不等于当事人收到日；期限起算采用哪一日须逐条核对并留正本与凭证。 |
| scrutiny / approval of the draft award | 机构核稿 | 部分机构在签发前审形式；是否须核稿、核稿处于生效或签发链条的哪一环，按适用规则核对。核稿期须独立于庭签署日计入时间表，与规则裁决期限分别计算。 |
| reasons for the award | 裁决理由 | 争点与理由是否一一对应、有无未回应争点，决定撤销与执行的攻击面；个别制度仅在当事人请求时给理由，须及时请求以免执行地被指无理由裁决。 |
| dispositive part / operative part | 主文（裁断部分） | 部分法域执行时只读取主文，故主文须写成可直接登记执行的句式：谁、于何日前、付多少、至何账户。 |
| correction of the award | 更正 | 针对计算、书写、印刷或类似性质的错误，以"原文—正确文字—正确数字"三件式请求，成立时以 addendum 作出并构成裁决一部分。 |
| interpretation of the award | 解释 | 针对主文含义歧义，须先指明具体语句及其如何影响权利义务与执行落地；只能说明已确定的内容，不能改变它。 |
| additional award | 补充裁决 | 就已提出而未裁断的请求补裁；能否由当事人申请、申请名称与窗口，按适用规则核对，先现查再定路径，不得以更正替代。 |
| revision | 复核（因发现决定性新事实） | 特定制度下因事后发现决定性事实而请求复核，与更正、解释不同，窗口与上限独立，须极早决定申请方向。 |
| set-aside / annulment | 撤销裁决（之诉） | 仲裁地法院消灭裁决的程序；事由、窗口与能否延展按仲裁地法核对，整体成功率低；提起撤销通常不中止对方的执行程序，但中止效果须按执行地法核对。 |
| grounds for setting aside | 撤销事由 | 与拒绝承认执行事由近似但清单不同，不得互抄；主张程序瑕疵者须自证当初已及时书面提出异议。 |
| appeal (on the merits / on a point of law) | 上诉 | 就实体或法律问题请求上级审查；仲裁裁决是否可上诉、可就哪类问题上诉、能否由条款排除，须按仲裁地法核对，不要把撤销写成上诉。 |
| recognition and enforcement | 承认与执行 | 承认是赋予裁决确定力地位，执行是动用强制手段；两步在部分法域同一程序、部分法域分离，路径与文件要求须逐地填表。 |
| leave to enforce | 执行许可 | 普通法下须先申请许可方能执行，可依单方申请启动但法院未必准许；不等于"申请强制执行"这一境内表述。 |
| grounds for refusal | 拒绝承认与执行事由 | 由被申请人举证，含协议效力、程序通知、超裁、组庭与程序不符、可仲裁性与公共政策；须逐地核对司法口径，不得以他国结论套用。 |
| certified copy / authentication / legalisation / apostille | 认证副本／验证／使领认证／附加证明书 | 执行文件链的形式要件，公证、认证与宣誓译本须自裁决作出前就开始准备，形式瑕疵可拖延数月。 |
| certified / sworn translation | 宣誓译本／认证译本 | 部分执行地要求官方语言译本并由特定人员认证；非权威语言的"我方自译"不得作为法源或正式附件。 |
| pre-award interest / post-award interest | 裁决前利息／裁决后利息 | 利息四要素（基数、利率或口径、起算日、单利或复利直至实际支付日）须在主文写满；裁决后利息未在主文或费用程序中提出，执行期无从主张。 |
| binding force / final and binding | 有拘束力／终局且有拘束力 | 条款常见表述，指当事人承诺履行并接受终局拘束；它不排除仲裁地法院的撤销程序与执行地的拒绝事由，不要写成"不可争议"。 |
| sovereign immunity from jurisdiction vs from enforcement | 管辖豁免／执行豁免 | 区分为两事：裁决可得承认不等于特定资产可被查封；被执行方为国家、国企或主权基金时须逐项核查资产商业性质与当地口径。 |
| res judicata | 既判力 | 裁决对已裁断事项（同一当事人、同一请求、同一原因）的确定力，是拒绝重开与主张承认的依据。 |
| issue estoppel | 争点禁反言 | 已实际决定并必要的具体争点不得再行争执，范围窄于既判力；中文没有完全对应词，保留英文并括注，不与既判力混用。 |
| claimant's evidential burden in enforcement | 执行阶段对被申请人举证的分配 | 拒绝承认与执行的事由一般由被申请人证明，申请人只需交付裁决正本或认证副本与仲裁协议；把举证责任说反会被法院直接驳回。 |

## 八、易混词对照

| 易混的一组 | 一句话切分 |
|---|---|
| jurisdiction / admissibility | 前者问"仲裁庭有没有权裁这个争议"，后者问"这个请求现在适不适合作实体处理（时效经过、前置条件未成就、请求未成熟）"；把可受理性写成管辖异议，等于替对方承认管辖。 |
| award / order / decision | 只有裁决具备裁决形式与依公约执行的路径，程序令与决定不在此列；金钱给付若只拿到 order，等于取得一个无法跨境执行的结果。 |
| seat / venue（hearing location） | 仲裁地决定仲裁地法与裁决国籍，开庭城市只是物理或远程的审理地点；只写开庭地而漏写 seat 会留下默认地陷阱。 |
| governing law of the contract / law of the arbitration agreement / lex arbitri / institutional rules | 四层分别是实体权利义务、条款效力、法院介入与撤销、以及当事人约定的程序规则；同一份文书里四层须各占一节，混写会让一项无效拖垮其余论证。 |
| security for costs / advance on costs / undertaking as to damages | 第一是命令申请人为对方费用提供担保，第二是双方分担机构与仲裁员报酬的预缴，第三是法院禁令下申请人对措施错误的赔偿承诺；三者对象、时点与后果全不同。 |
| joinder / consolidation / multiple contracts | 追加是把案外人拉进既存程序，合并是把已存在的数个程序并成一个，多合同是在一案里依数份仲裁协议处理关联合同；截止点与决定者各不相同。 |
| nomination / appointment / confirmation | 提名是一方提出人选，任命使其就任，确认是机构对提名的核验；把三者混用会误判"提名机会已否丧失"。 |
| independence / impartiality / disclosure duty | 独立性看关系，公正性看态度，披露义务看是否把可能引起正当怀疑的事实讲出来；挑战申请必须指明攻的是哪一条并附对应事实。 |
| justifiable doubts / actual bias | 标准是"客观第三人是否会正当怀疑"，不是"证明确有偏私"；按后者立论会因举证不能而整体被驳。 |
| correction / interpretation / additional award | 分别是改文字与数字、说明主文歧义、就漏裁请求补裁；凡需重新论证事实或法律才能得到结果的，属于上诉或撤销路径，不要伪装成上述三者。 |
| set-aside / refusal of enforcement / appeal | 撤销在仲裁地消灭裁决，拒绝执行在执行地阻断强制，上诉是实体复审；三者法院、事由清单与期限各自独立，且撤销地败诉不必然断送执行地抗辩。 |
| res judicata / issue estoppel / lis pendens | 已决事项整体不得重开、已决定的具体争点不得再争、同一争议在别处尚未审结；三者时间方向不同，混用会把未决说成已决。 |
| without prejudice / privileged / confidential | 前者是磋商内容不得在实体阶段援引，中者是拒绝披露的法定理由并须日志支持，后者是保密义务与保密令的处理档位；同一份文件可能三者并存而后果各异。 |
| admitted / denied / no admission made | 承认、正面否认、以及信息不足时不作承认；只用前两态会在不自知中作出过度承认或构成对某项事实的默认。 |
| counterclaim / set-off / cross-claim | 反请求是向申请人提出的独立请求，抵销是以互负债务抵充对方请求的抗辩或请求，交叉请求是向其他被申请人提出；方向写错请求即落空。 |
| document production / discovery / depositions | 文件披露只交文件且不录取证言；把美式开示与庭外录取证言写进请求，会被规则明文排除或以不成比例驳回。 |
| relevance / materiality | 相关是"与争点相连"，材料是"缺了会怎样影响结论"；合成一句等于两栏都空。 |
| limitation / time limit | 前者是准据法上的实体期间，届满可能消灭请求权；后者是规则或程序令上的程序期间，可申请延展；中文都叫"时效／期限"时最容易出错。 |
| default (non-participation) / default (event of default) | 一个是未参与程序、不阻却组庭与推进，一个是合同项下的违约事件、触发解除与加速到期；同一文书两意并存时须分别用词。 |
| interim award / partial award | 前者强调措施的临时效力与可执行形式，后者强调只裁部分请求但对该事项终局；把 partial 说成"未生效"会被法院纠正。 |
| institution / arbitral tribunal / state court | 机构管收发、任命与核稿，仲裁庭裁本案，法院管撤销、协助与执行；英文 "court" 出现时必须限定是哪一类，否则读者只会理解为国家法院。 |
| reservation of rights / waiver | 保留权利声明某行为不构成放弃，弃权是明示或以行为放弃；未在同意程序安排时写保留，事后可能被认定为已弃权。 |
| memorandum / minute / note | 三方备忘、纪要与机构实务指引性质与拘束力不同，机构出具的实务指引不具拘束力，不得作为驳回或准许的依据。 |

## 九、使用与核验纪律

- 摘用方式：《中文审阅说明》的术语表按"英文原文—中文通行译法—一句说明"摘 3 至 8 条，只放本案文书实际出现的词；英文文书中同一术语全篇一个译法。
- 保留原文的情形：机构名、规则名与版本年份、书状与程序令的正式名称、条款原文引述、机构特有机关名，保留英文并括注中文，不译成"看起来更顺"的别名。
- 需现查的量化要素：一切天数、金额门槛、份数、费率与条号都不入本表，按 `references/forum-rules-matrix.md` 的核验流程用 `scripts/fetch_official.py applicable` 定版本、`lookup` 命中原文再落笔。
- 分层核对：机构规则与仲裁地法（lex arbitri）分两层、软法指引只作分类语言不作拘束依据；涉外法域的实体口径转 `skills/11-governing-law` 分层标注置信度。
- 一致性自检：术语、当事方名称、金额、关键日期在配对文书之间须一致，交付前跑 `scripts/verify_suite.py --workdir <案件目录>`，其中 CONSIST 与 XREF 会拦下术语漂移与段落引用错位。
