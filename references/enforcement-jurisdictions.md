## 一、选定任务与目标
配合 `14-cross-border-enforcement` 使用；本参考提供核验问题，不提供静态国别答案、期限或成功率。
先区分承认文书、采取措施、处置资产和实现回款，不能合称“可以全球执行”。
按当前任务选 `forecast`、`plan`、`asset`、`immunity`、`insolvency`、`board` 或 `counsel`。
`filing` 是选定目标的提交核验阶段，不另造 profile；裁决前 forecast 不要求已有裁决。
目标使用 T-；主表仅在 `enforcement-plan.yaml`，案件矩阵只引用，不重复维护资产事实。
逐份识别文书：仲裁裁决、程序决定、法院判决、和解或其他文件，不因标题相近直接套执行路线。
识别投资条约或 ICSID 信号后转专业律师；不能把全部投资争端文书当作同一种机制。
无法定位资产时先建调查候选与任务，不能将候选地或集团业务足迹登记为已核实财产。
每个结论标依据、核验日、置信度和适用范围；未知列负责人、工作截止及受影响节点。

## 二、逐目标官方核查卡
每一 T- 独立填卡；同一国家内不同地区、法院、资产或文书可能需要分开核查。
下表“官方核查入口”是来源类别，实际机关、文献及链接须取得后记录，不凭记忆填写。

| 字段 | 官方核查入口 | 逐目标要回答的问题 |
|---|---|---|
| 地域与文书 | 法院及法律公布机关 | 目标法律区域如何划分；文书在此处属于何种裁决或其他文书？ |
| 执行路线 | 条约保存机关、实施法及法院原文 | 条约范围、保留、地域及时间适用如何；国内法、区际或其他路径有何条件？ |
| 裁决状态 | 原程序记录、作出地及目标地法院文件 | 文书是否具备所需效力；更正、补充、撤销、暂停或中间性质有何影响？ |
| 法院与连接点 | 现行管辖法、司法机关规则 | 哪一法院、级别和地域有权；仅承认与具体措施的连接点是否不同？ |
| 程序与送达 | 法院规则、官方办事指引及裁判 | 启动方式、申请范围、通知、送达、听证和异议要求分别是什么？ |
| 期限 | 法律、法院规则及有关裁判 | 期间、起算事件、证据、时区、日历、暂停／中断／延展及救济如何核算？ |
| 审查与抗辩 | 实施法及目标法院裁判全文 | 可仲裁性、公共政策、程序保障等由谁提出和证明；可否依职权审查？ |
| 保全与担保 | 措施法、法院规则及命令 | 权限、证明标准、通知方式、担保、后续启动、比例及错误措施责任如何？ |
| 资产与责任 | 官方财产登记、公司登记及法院记录 | 所有人、债务人、第三人负担、执行豁免和责任扩展依据是否分别成立？ |
| 豁免 | 适用法律、条约及相关裁判 | 管辖豁免与执行豁免的主体、例外、放弃及具体资产用途如何分别判断？ |
| 破产 | 破产登记、启动／承认命令及法律 | 中止何时发生、涵盖哪些主体资产与地域；申报、许可及顺位如何处理？ |
| 制裁与支付 | 有权制裁、支付或外汇监管机关 | 主体、资产、服务与支付路径是否受限；是否需要许可且由谁取得？ |
| 文件与译本 | 法院清单、认证主管机关规定 | 哪些原件／副本、译本、认证及电子格式被接受，依据和完成证据是什么？ |
| 代理与费用 | 法院、专业监管机构及官方收费表 | 代理资格、委托权限、签署、费用和保证金要求分别是什么？ |
| 救济与协调 | 法院程序规则、裁判及平行程序文件 | 裁定救济、暂停、担保、其他执行和已收款披露要求是什么？ |

逐格留“问题—权威—命题—反向权威—效力与时间适用”，方法见 `global-research-protocol.md`。
来源卡须含发布机关、标题、文献号、版本、原文定位、真实链接或存档、核验人和日期。
条约状态不代替国内实施法；官网办理摘要不代替适用法与裁判，也不保证本案可受理。
期限字段必须附真实起算事件与证据；查不到写 unknown，不将律师报价工期当法定期限。

## 三、地区差异研究问题
以下按研究对象分组，均为待答问题；不意味着相关制度在每个地区存在或适用。

| 目标范围 | 向官方材料或当地律师提出的问题 |
|---|---|
| 中国内地 inbound | 文书来自何法律区域、应查何种承认安排；法院管辖、审查／报核、期限及文件要求怎样适用于本案？ |
| 中国企业 outbound | 每个境外目标的文书分类、条约实施与连接点是什么；中国法院程序在当地是否有任何相关性及依据？ |
| 香港、澳门、台湾相关目标 | 应核何种区际或其他安排及文书分类；本地承认与具体财产措施是否分阶段、由何机关办理？ |
| 东亚与东南亚目标 | 地方管辖、语言、译本、电子提交及资产调查权限如何；保全与后续承认之间有哪些条件？ |
| 欧洲各目标 | 国家、区域及次国家规范是否同时适用；对本案文书和当事人，彼此范围、排除与冲突如何处理？ |
| 北美目标 | 联邦、州、省或其他层级各管何事；所选法院的连接点、财产程序和债务人调查权限是什么？ |
| 拉美与加勒比目标 | 国内法、双边或区域安排何者可用；司法分工、译本认证和当地代表要求如何影响文件准备？ |
| 中东及北非目标 | 是否存在不同法院体系或特定区域制度；其权限、相互承认及境外资产措施边界是什么？ |
| 南亚目标 | 目标文书适用范围、官方指定或实施条件是否需要特别核查；法院层级、担保与送达依据是什么？ |
| 撒哈拉以南非洲目标 | 是否涉及区域统一规则、共同法院或国内规则；其文书范围、当地程序及资产登记如何衔接？ |
| 大洋洲及岛屿目标 | 全国、州或领地规则如何分工；境外送达、财产所在地和电子文件要求如何影响本目标？ |
| other / mixed | 多区域资产、海上或移动资产、数字权益如何定位；何种连接点及第三人程序须分别查证？ |

同一区域不能共享未核答案；比较时列“已核差异／待核问题／对当前动作的影响”。
不凭营商印象、法系标签或历史成功案例给执行概率；法律条件与商业回收假设分列。

## 四、权属、集团与合法调查
每项财产分开记录债务人、登记所有人、实际权属证据、位置、类型、负担及可变现资料。
集团控制、共同品牌、合并财报与子公司账户不等于债务人资产；持股不等于拥有子公司财产。
担保、共同责任、揭开面纱、财产转移撤销或追索均需独立基础、适格主体与程序核验。
公司登记只能证明其记载范围；受益所有人信息或公开资金流线索不能替代财产权证明。
合法查询可覆盖公司、不动产、股权、应收、设备、船舶、航空器、知识产权及其他可识别权益。
银行或平台资产核实通过合法渠道与有权程序，不社工、侵入系统或购买非法数据。
资产估值、优先负担、流动性、处置成本及转移迹象各留证据；线索不能直接变成预计回款。
仅申请承认是否需具体资产须核当地法；查封特定财产须核其权属、责任和程序基础。

## 五、豁免、破产及平行程序
**管辖豁免单核**：主体法律地位、行为性质、适用法、例外、同意或放弃及有效权限。
**执行豁免另核**：特定资产所有人、实际用途、保护类别、放弃措辞及措施条件。
国企身份不自动产生豁免；仲裁同意不当然放弃执行豁免，商业用途也不自动允许扣押。
**破产效力范围单核**：区分申请、启动命令、境外承认及当地辅助命令，逐一取得文本。
分别记录时间、地域、主体、财产、中止行为、例外和许可；不能把一处破产写成全球中止。
核债权申报、顺位、担保、抵销、撤销权和分配；集团程序不当然合并财产与债务。
对撤销、承认、保全、破产、和解及付款保持统一事实，核各地暂停、担保和披露问题。
其他地点受理、拒绝或撤销的后果须在本目标另核，不能自动推定全球终结或全部无影响。

## 六、回收抵减与多币种
按 AW-/R- 建共同回收底账，记录本金、利息、费用、付款日、币种、付款人及凭证。
各目标的收款及时反馈并按已核口径抵减；担保、保险、和解及破产分配协调，禁止重复受偿。
查封、冻结、保证金、判决和未交付的变卖款不等于债权人实收，分别标状态。
抵减顺序、利息截止和跨币种换算法律口径单独核验；不同币种不得直接相减。
多币种预算原币分列，未知成本不填零；担保本金占用与实际费用分开。
管理折算另列汇率、日期、来源和用途，不覆盖原币余额；无确认汇率不跨币种合计。
情景仅基于明确资产与成本假设，不编回收率；协调律师核查支付限制及必要许可。

## 七、文件认证与当地代理
逐文件列裁决与更正／补充、协议及并入件、送达记录、主体、授权和拟申请所需证据。
分别确认原件、认证副本、电子件与证明方式；文件身份、完整性及程序用途不能混为一项。
翻译、认证翻译、公证、领事认证、Apostille 或电子认证逐项核条件，不一律叠加。
记录适用地域、文件类别、主管机关、接收法院要求、译者资格及完成凭证，不凭公约名称放行。
当地代理另列资格、冲突核查、已聘状态、委托范围、签署权限、费用授权和沟通负责人。
认证办妥不等于律师获授权；律师接受委托不等于文件或提交条件已核验。
对外法院申请和表格由当地律师制作，本套件提供材料与核验指示，不冒充法院代理。

## 八、阶段、闸门与交接
forecast 按 14 的十二项预判记录基础、缺口和裁决前修补；不编裁决主文或日期。
plan／counsel 可保留 unknown，继续合法调查、研究、预算及律师委托，不要求先通过 filing。
filing 只检查明确选定的目标与申请范围；未选择目标不能宣称具备提交条件。
提交前须核路线、期限证据、法院连接点、文件链、授权、相应资产责任及专项障碍处理。
关键核验未闭合即阻断受影响提交；结构通过、布尔确认、用户同意或高置信度不能绕门。
board 仅在需要时做五节决策、分币种现金影响、期限或核验任务、风险与授权，不代替 filing。
受控草案登记 Q 与 `pending.json`，实质缺项另跟踪；正式交付配 Word；执行申请或律师指示为非中文时另配中文审阅说明。
交接写目标、问题、最小材料、所需权威、假设、预算、负责人和交付日，外发与递交分别获授权。
